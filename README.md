# História Quest — versão sem pastas

Todos os arquivos do projeto ficam diretamente nesta pasta: `index.html`, `style.css`, `app.js`, `server.js`, arquivos do banco e `logo-historia-quest.png`.

## Como executar
1. Instale o Node.js 22.5 ou superior.
2. Abra esta pasta no VS Code.
3. No terminal, execute `npm install`.
4. Execute `npm start`.
5. Acesse http://localhost:3000.

A interface carrega o CSS pelo caminho relativo `style.css` e o JavaScript por `app.js`, sem depender de subpastas. Para login, cadastro e progresso com banco de dados, execute pelo servidor; abrir apenas o HTML com duplo clique não inicia a API.

Conta de demonstração: `aluno@historiaquest.local` / `Historia123!`
